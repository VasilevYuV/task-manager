## <span>🎯 Обзор</span>

<p id="обзор">
Task Manager - это Spring Boot REST API приложение для управления задачами. Демонстрирует чистую архитектуру, валидацию данных, обработку ошибок и полную интеграцию фронтенда с бэкендом в одном монолитном приложении.

Приложение предоставляет полный CRUD (Создание, Чтение, Обновление, Удаление) интерфейс для управления задачами с валидацией в реальном времени и интуитивно понятным пользовательским интерфейсом. Идеально подходит для изучения основ Spring Boot или как стартовая точка для более сложных приложений.
</p>

## <span>🚀 Установка</span>
<a id="установка"> </a>

### Предварительные требования

- **Java 21** или выше
- **Maven 3.8** или выше
- **Git** (опционально, для клонирования)

### Локальная установка

1. Склонируйте или скачайте проект
2. Перейдите в директорию проекта
3. Соберите проект: mvn clean compile
4. Запустите приложение: mvn spring-boot:run

Альтернативный вариант: Соберите JAR и запустите:
```bash
mvn clean package
java -jar target/task-manager-1.0.0.jar
```
### Настройка в IDE (IntelliJ IDEA)

1. Откройте проект: File → Open → Выберите директорию проекта
2. Включите авто-импорт: Когда появится запрос, включите Maven auto-import
3. Установите JDK: File → Project Structure → Project SDK → Java 17
4. Конфигурация запуска:
   - Нажмите "Add Configuration" → "Spring Boot"
   - Главный класс: com.taskmanager.TaskManagerApplication
   - Нажмите "OK"

### Проверка установки

После запуска откройте браузер и перейдите по адресу:
http://localhost:8080

Вы должны увидеть интерфейс Task Manager.

## <span>🎮 Использование</span>
<a id="использование"> </a>

### Веб-интерфейс

1. **Создание задачи**:
   - Заполните форму в верхней части страницы
   - Заголовок: 3-100 символов (обязательно)
   - Описание: до 500 символов (опционально)
   - Статус: выберите из списка (обязательно)
   - Срок выполнения: укажите дату и время (опционально)
   - Нажмите "Сохранить"

2. **Просмотр задач**:
   - Все задачи отображаются в таблице ниже
   - Используйте фильтры для просмотра задач по статусу
   - Нажмите на кнопку "✏️" для редактирования задачи
   - Нажмите на кнопку "🗑️" для удаления задачи

3. **Фильтрация**:
   - "Все" - показать все задачи
   - "TODO" - только задачи для выполнения
   - "IN_PROGRESS" - задачи в процессе
   - "DONE" - выполненные задачи

### REST API

Приложение предоставляет REST API по адресу: http://localhost:8080/api/tasks

Примеры запросов с использованием curl:
```bash
GET /api/tasks - получить все задачи
curl -X GET http://localhost:8080/api/tasks

GET /api/tasks/{id} - получить задачу по ID
curl -X GET http://localhost:8080/api/tasks/a1b2c3d4-...

POST /api/tasks - создать новую задачу
curl -X POST http://localhost:8080/api/tasks \
  -H "Content-Type: application/json" \
  -d '{"title":"Новая задача","description":"Описание","status":"TODO"}'

PUT /api/tasks/{id} - обновить задачу
curl -X PUT http://localhost:8080/api/tasks/a1b2c3d4-... \
  -H "Content-Type: application/json" \
  -d '{"title":"Обновленная задача","status":"DONE"}'

DELETE /api/tasks/{id} - удалить задачу
curl -X DELETE http://localhost:8080/api/tasks/a1b2c3d4-...
```

## <span>📚 API документация</span>
<a id="api-документация"> </a>

### Базовый URL
http://localhost:8080/api/tasks

### Методы API

#### GET /api/tasks
Возвращает список всех задач.

**Ответ:**
Статус: 200 OK
Тело: Массив объектов Task

Пример ответа:
```
[
  {
    "id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
    "title": "Купить молоко",
    "description": "1 литр, 2.5%",
    "status": "TODO",
    "createdAt": "2024-01-15T10:30:00",
    "dueDate": "2024-01-16T18:00:00"
  }
]
```
#### GET /api/tasks/{id}
Возвращает задачу по указанному ID.

**Параметры:**
- id (path): UUID задачи

**Ответы:**
- 200 OK: Задача найдена
- 404 Not Found: Задача не найдена

#### POST /api/tasks
Создает новую задачу.

**Тело запроса (JSON):**
```
{
  "title": "Новая задача",      // обязательно, 3-100 символов
  "description": "Описание",    // опционально, до 500 символов
  "status": "TODO",            // обязательно: TODO, IN_PROGRESS, DONE
  "dueDate": "2024-12-31T23:59:59" // опционально, должна быть в будущем
}
```

**Ответы:**
- 201 Created: Задача создана успешно
- 400 Bad Request: Ошибка валидации

**Заголовки ответа:**
Location: /api/tasks/{новый-id}

#### PUT /api/tasks/{id}
Обновляет существующую задачу.

**Параметры:**
- id (path): UUID задачи для обновления

**Тело запроса:** Аналогично POST

**Ответы:**
- 200 OK: Задача обновлена
- 400 Bad Request: Ошибка валидации
- 404 Not Found: Задача не найдена

#### DELETE /api/tasks/{id}
Удаляет задачу.

**Параметры:**
- id (path): UUID задачи для удаления

**Ответы:**
- 204 No Content: Задача удалена
- 404 Not Found: Задача не найдена

### Ошибки валидации

При ошибке валидации возвращается структурированный ответ:

Статус: 400 Bad Request
Тело:
```
{
  "timestamp": "2024-01-15T10:30:00",
  "status": 400,
  "message": "Validation failed",
  "errors": [
    {
      "field": "title",
      "message": "Title must be between 3 and 100 characters"
    }
  ]
}
```
### Модель данных

#### TaskStatus (Enum)
- TODO: Задача для выполнения
- IN_PROGRESS: Задача в процессе
- DONE: Задача выполнена

#### Task (Record)
- id: UUID (автоматически генерируется)
- title: String (обязательно, 3-100 символов)
- description: String (опционально, до 500 символов)
- status: TaskStatus (обязательно)
- createdAt: LocalDateTime (автоматически устанавливается)
- dueDate: LocalDateTime (опционально, должна быть в будущем)

Запуск всех тестов:
mvn test

Запуск только unit-тестов:
```bash 
mvn test -Dtest=TaskServiceTest
```

```bash
mvn test -Dtest=TaskControllerTest
```
